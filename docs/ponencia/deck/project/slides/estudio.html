SIGMA · Sistema Integral de Gestión de Materiales de Aprendizaje

4

La primera innovación es el estudio de mercados. El sistema replica el formato oficial de análisis de precios. Para cada artículo calcula la dispersión con el coeficiente de variación, sugiere qué cotización es atípica, y cuando faltan cotizaciones usa los precios históricos indexados con IPC más puntos adicionales. Al final exporta el Excel con la misma estructura de las hojas L1 a L11 que se firman. En la pantalla ven el lote Agrícola con sus 243 artículos y el método con el que se obtuvo cada precio.
